# Security Policy

## Supported Versions

Currently, we support the `main` branch for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Pugu, please **do not** open a public issue.

Instead, please send an email to our security team at: **support@questpage.app**.

We take all security reports seriously and will respond as quickly as possible. Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact.

We will work with you to verify and resolve the issue before public disclosure.
