Thanks for installing LifeOS — Headless productivity OS.

1. Get the application URL by running these commands:
{{- if .Values.ingress.enabled }}
  http{{ if .Values.ingress.tls }}s{{ end }}://{{ .Values.ingress.host }}
{{- else }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-web {{ .Values.service.web.port }}:{{ .Values.service.web.port }}
